# Tron / eDEX-UI Theme for Home Assistant

A dark cyberpunk theme for Home Assistant: black background, cyan `#39f3ff`
primary with amber `#ff9d2e` accent, Share Tech Mono font, subtle CRT
scanline overlay. Inspired by Tron and eDEX-UI.

## Install

Via HACS: search "Tron eDEX-UI Theme" under Frontend > Themes, install, then
restart Home Assistant (or reload themes: Developer Tools > YAML > Themes).

Select it under Settings > Appearance > Theme, or set it as the backend
default under Settings > System > General (or ask Claude to set it via the
`ha_manage_theme` tool). Switching back to the built-in "Default" theme at
any time does not require removing this one — both coexist.
